# Arbitrary Precision Calculator in C

A console-based Arbitrary Precision Calculator developed using C programming language.

## Features

- Addition of very large numbers
- Subtraction of large numbers
- Multiplication of large numbers
- Division operation
- Handles numbers beyond normal integer limits
- Command-line execution
- Modular arithmetic implementation

## Technologies Used

- C Language
- Data Structures
- Linked Lists
- Dynamic Memory Allocation
- File Handling
- Modular Programming (Header Files)

## How to Run

### Compile

```bash
gcc main.c add.c sub.c mul.c div.c -o apc
```

### Run

```bash
./apc
```
